1. Who operates this application

This application is operated by a single individual for their own personal use (GitHub: @tkyskf). It is not operated by, or on behalf of, any company or organization. There are no other users.

本アプリは個人が自身の利用のために運用しているものです。企業・組織による運用ではなく、運用者以外の利用者は存在しません。

2. What data is accessed

The application accesses Google Calendar data belonging to the Google Account that authorizes it — that is, the operator's own account. It requests the following OAuth scopes:

ScopeWhy it is needed
calendar.readonly To read the list of calendars and their events, so that the day's schedule can be shown inside Obsidian.
calendar.events To create and update events, so that changes made in Obsidian can be written back to the calendar.

No other Google data is requested. The application does not access Gmail, Drive, Contacts, or any other Google service.

取得するのは、認可を行った Google アカウント（運用者本人のもの）のカレンダー情報のみです。 上記2つのスコープ以外は要求せず、Gmail・Drive・連絡先などの他サービスにはアクセスしません。

3. Where data is stored

All data stays on the operator's own device. Calendar events retrieved from the Google Calendar API are held in memory and written into a local Obsidian vault — a folder of plain Markdown files on the operator's personal computer.

OAuth credentials (the access token and refresh token issued by Google) are stored locally in the Obsidian plugin's configuration file on the same device. The OAuth redirect used on desktop is http://127.0.0.1:42813/callback, a loopback address on the operator's own machine.

There is no server, no hosted backend, and no database operated by this application. Calendar data is never transmitted anywhere except directly between the operator's device and Google's own APIs.

取得したカレンダー情報は運用者の端末内のローカルな Obsidian vault（Markdown ファイル群）に保存されます。 OAuth のトークンも同じ端末内のプラグイン設定ファイルに保存されます。本アプリはサーバもデータベースも持たず、 カレンダー情報が運用者の端末と Google の API 以外の場所へ送られることはありません。

4. What is not done

  • Data is not sold, rented, or shared with any third party.
  • Data is not used for advertising, profiling, or any form of marketing.
  • Data is not used to train machine learning or AI models.
  • No analytics, telemetry, tracking, or crash-reporting is collected by the operator.
  • No data is transferred to any human other than the operator.

5. Limited Use disclosure

This application's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

本アプリによる Google API から取得した情報の利用および転送は、Limited Use（限定的な使用）の要件を含む Google API Services User Data Policy に準拠します。

6. Retention and deletion

Because there is no server, there is nothing for the operator to delete on anyone's behalf. Notes and cached calendar data can be removed at any time by deleting the relevant files from the local Obsidian vault. Stored OAuth tokens are removed by signing out within the plugin's settings.

7. Revoking access

Access granted to this application can be revoked at any time from Google Account › Third-party apps & services. Revoking access immediately invalidates the stored tokens.

8. Children

This application is not directed at children and is not used by anyone other than its operator.

9. Changes to this policy

If this policy changes, the revised version will be published on this page with an updated effective date.
