tkyskf Calendar Sync

A single-user application that brings Google Calendar events into a personal Obsidian vault.
Google カレンダーの予定を個人の Obsidian vault に取り込むための、単一利用者向けアプリケーションです。

What this application does

This application reads calendar events from the operator's own Google Account and displays them inside Obsidian, a local note-taking application running on the operator's personal computer. It is used to keep a daily note in sync with the day's schedule, and to create notes that are linked to individual calendar events.

It can also create and update events in the connected calendar, so that a note written in Obsidian can be reflected back onto the calendar.

本アプリは、運用者本人の Google アカウントからカレンダーの予定を読み取り、個人の PC 上で動作する ローカルのノートアプリ Obsidian に表示します。日次ノートとその日の予定を同期させること、および 個々の予定に紐づくノートを作成することを目的としています。Obsidian 側で書いた内容をカレンダーへ 反映できるよう、予定の作成・更新も行います。

Who can use it

This is a personal, single-user deployment. It is not offered as a service, it is not distributed, and no accounts other than the operator's own are authorized to use it.

本アプリは運用者本人のみが使用する個人利用のものです。サービスとして提供しておらず、配布もしておらず、 運用者本人以外のアカウントによる利用は想定していません。

How it is built

The application is the open-source Obsidian community plugin obsidian-google-calendar, configured with the operator's own Google Cloud OAuth client so that authorization and token storage stay on the operator's own device.

Data and privacy

Calendar data stays on the operator's device. There is no server, no database, no analytics, and no transfer of data to any third party.

Full details are in the Privacy Policy.

カレンダーのデータは運用者の端末内に留まります。サーバもデータベースも解析も無く、第三者への提供も行いません。 詳細はプライバシーポリシーをご覧ください。
